# Profile Positioning Brief

> Rule: no unsupported claims. Be honest, specific, and concrete. No hype, no keyword stuffing. Mark any unproven proof point with "[needs evidence]". Copy blocks are in fenced code blocks so they paste cleanly.

## One-liner
> One sentence that says who you are and the value you deliver. Under 120 characters.

```text
[one-liner]
```

## Short bio
> 2-3 sentences for the profile header. Specific, plain, no buzzwords.

```text
[short bio]
```

## Long bio / about
> A fuller paragraph for the profile About area or an external CV. Lead with what you build and for whom.

```text
[long bio / about]
```

## Credibility bullets
> Proof points a skeptical reader would accept. Mark anything not yet backed by evidence with "[needs evidence]".

```text
- [proof point]
- [proof point] [needs evidence]
```

## Featured work
> The few repositories, Spaces, or Collections to surface first, each with a one-line reason it earns the spot.

```text
- [repo or Space]: [why it is featured]
```
